# Adaptadores de $video

| Caso | Adaptador | Condición |
|---|---|---|
| Vídeo largo a clips | clipify-es-pro | CPU + FFmpeg + Whisper |
| Subtítulos premium | pycaps/Remotion | fijar versión; validar estado alfa |
| Tema a vídeo masivo | MoneyPrinterTurbo | contenedor aislado; proveedores aprobados |
| Montaje premium | OpenMontage | revisar AGPL y costes externos |
| Avatar | proveedor/modelo vigente | consentimiento + GPU/API |
| B-roll generativo | motor vigente | GPU compatible o API autorizada |

No instalar todos los adaptadores por defecto. La super-skill solo enruta hacia los ya disponibles o presenta un plan de instalación separado.
